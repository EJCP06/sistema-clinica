RESUMEN DETALLADO DE PREGUNTAS Y RESPUESTAS - REESTRUCTURACIÓN DE MÓDULOS

1. PREGUNTA: ¿Cómo llamo a los pacientes en estado "sala de espera" a través de llamados laboratorio e imágenes, si actualmente esos usuarios solo pueden ver las tablas (como APS)?

RESPUESTA DETALLADA:
Actualmente, el problema es que el sistema asocia el botón de "Llamar" a la existencia de un Consultorio físico. Para Laboratorio e Imágenes, el proceso se resuelve así:
* El Backend ya está preparado: Aunque no tengan un consultorio médico, el servidor puede buscar al siguiente paciente filtrando por el "ID de Servicio" (Laboratorio o Imágenes).
* En lugar de mostrar "Consultorio 5", el sistema puede configurarse para que en el Turnero Público aparezca el nombre del servicio, por ejemplo: "Turno L-001 -> Pase a: LABORATORIO".
* Para que el usuario pueda llamar, necesitamos habilitar el "Panel de Llamado" (el que tiene el botón azul grande) para estos roles, permitiendo que el sistema tome al primer paciente en cola de "Sala de Espera" que pertenezca a su área.

2. PREGUNTA: ¿Cómo entraría a esas vistas aparte desde el login (Llamados Laboratorio y Llamados Imágenes)?

RESPUESTA DETALLADA:
La mejor forma de gestionar esto es mediante el "Perfil de Usuario Inteligente":
* Cuando un empleado inicia sesión, el sistema verifica su perfil en milisegundos.
* SI EL USUARIO TIENE PUESTO ASIGNADO: El sistema asume que es un técnico que va a atender pacientes y lo envía directamente al "Panel de Llamados" (la vista con el botón azul y el cronómetro).
* SI EL USUARIO NO TIENE PUESTO ASIGNADO: El sistema asume que es un recepcionista y lo envía directamente a la "Tabla de Atención" (la vista tipo APS para gestionar la cola).
Esto permite que, usando el mismo Login, cada persona llegue exactamente a la herramienta que necesita para trabajar ese día.

3. PREGUNTA: ¿Por qué no quiero que el sistema me envíe a una vista u otra por defecto, sino que sean apartes como APS y Médicos? ¿Hay alguna opción?

RESPUESTA DETALLADA:
Sí, la opción es crear "Rutas Independientes". Esto significa que el sistema tendrá direcciones web únicas para cada tarea, igual que APS y Médicos:
* Ruta /atencion-laboratorio: Exclusiva para la tabla de recepción y gestión de seguros.
* Ruta /llamados-laboratorio: Exclusiva para el panel de llamar pacientes.
Al separarlos así, logramos:
* Independencia Total: El que está en recepción no ve botones de llamado que no usa, y el técnico no se distrae con la tabla de recepción.
* Especialización: Cada pantalla se diseña al 100% para su tarea específica, evitando conflictos visuales y errores de usuario.

4. PREGUNTA: ¿Cómo hacemos con los consultorios si actualmente estos dependen de las especialidades?

RESPUESTA DETALLADA (OPCIÓN 2 - MEJORA ESTRUCTURAL):
Para evitar que Laboratorio e Imágenes dependan de especialidades médicas, la mejor solución es independizar los consultorios:
* Cambio en Base de Datos: Hacemos que un consultorio pueda pertenecer directamente a un "Servicio" (como Laboratorio) sin necesidad de pasar por una "Especialidad".
* Formulario Inteligente en Administración: Cuando creas un usuario con rol "Laboratorio", el sistema oculta automáticamente el campo de "Especialidad" y te muestra un campo de "Consultorio Directo".
* Filtro de Servicio: En ese campo solo verás los puestos que tú marcaste como "Laboratorio" (ej: Puesto 1, Cabina A). Esto evita que mezcles consultorios médicos con puestos de laboratorio.

5. PREGUNTA: ¿Y si en vez de eso solo creo una especialidad llamada laboratorio y una llamada imagenes con sus consultorios? ¿Cómo funcionaría?

RESPUESTA DETALLADA:
Esta opción es muy válida y es la más rápida porque usa la lógica que ya tienen los médicos:
* Configuración: Creas la especialidad "Laboratorio" y le asignas sus consultorios.
* Personal de Llamado: Le asignas la especialidad "Laboratorio" y el Consultorio #1. Al entrar, el sistema ve que tiene consultorio y le muestra el botón azul de llamar.
* Personal de Recepción: Le asignas la especialidad "Laboratorio" pero DEJAS EL CONSULTORIO VACÍO. El sistema, al ver que no tiene puesto asignado, lo manda directo a la tabla tipo APS.
Es una forma de usar el sistema actual de forma creativa para separar las funciones sin cambiar el código base.

6. PREGUNTA: ¿No hay una forma de reestructurar este sistema para que sea de forma individual y fácil de entender?

RESPUESTA DETALLADA:
La propuesta es un "Sistema de Módulos Autónomos":
* Casa Propia: Laboratorio e Imágenes dejan de ser "invitados" en la vista de los médicos. Cada uno tiene su propia carpeta, sus propios archivos y su propia lógica.
* Interfaz Unificada: El usuario entra a su módulo (ej: Laboratorio) y tiene dos pestañas claras: [RECEPCIÓN] y [LLAMADOS].
* Orden y Crecimiento: Esta estructura es la más profesional porque si mañana quieres agregar "Farmacia" o "Rayos X", simplemente creas un nuevo módulo autónomo que no afecta a los demás. El sistema se vuelve modular, limpio y muy fácil de mantener a largo plazo.
